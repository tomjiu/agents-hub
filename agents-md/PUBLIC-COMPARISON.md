# 公开实现对照：0.2 草稿的缺口与修订建议

本报告记录 0.2 草稿阶段的公开对照，当时未修改基础模板；后续落实情况见 [0.3 审阅说明](REVIEW.md#030-公开对照后的落实)。读取的是调查当时的公开页面内容；未锁定上游 commit，不能用作可复现版本锁。网络检索接口余额不足，改为直接读取已知官方文档和公开仓库；本报告不是全网穷尽调查。

## 已读取的来源

1. [AGENTS.md 官网](https://agents.md/)：定位为代理的项目说明，包含 setup、测试、风格等项目事实。
2. [agentsmd/agents.md 仓库自身规则](https://github.com/agentsmd/agents.md/blob/main/AGENTS.md)：开发服务器与生产构建的区别、依赖锁文件同步、修改依赖后重启。
3. [VS Code Copilot Instructions](https://github.com/microsoft/vscode/blob/main/.github/copilot-instructions.md)：层级依赖、精确命令、复用 watcher 与验证结果、取消传播、资源释放、本地化、公开内容审查。
4. [Claude Code Best practices](https://code.claude.com/docs/en/best-practices)：短而具体的规则、按范围加载、明确验证命令、文字规范与 hooks/权限等强制机制的区别。

Codex 仓库根 AGENTS.md 原始地址返回 404；Codex 指南地址跨域跳转未继续读取；OpenCode 文档请求失败。这些不能作为本次已验证的依据。

## 当前两处应修正的表述

1. “模拟仅用于明确隔离的单元边界”过窄。集成测试也可能合法使用服务模拟或沙箱。建议改成：允许明确标注的测试替身和合成夹具；不得将替身结果冒充真实服务或端到端验收。真实数据并不意味着必须使用生产数据。
2. “105 行”不能等同于轻量。中文长条目可以在少量行内承载大量指令。以内容必要性、重复程度及实际加载预算衡量；不为了追求某个行数合并成长句，也不强加未经测量的 token 阈值。

## 不建议照搬

- VS Code 的格式风格、内部服务名、工具和目录均为其项目约定，不是通用要求。
- agents.md 网站仓库禁止交互期间 production build 是其 Next.js 开发环境约束，不应推广到 Rust 或所有前端项目。
- Claude 的 hooks、路径规则和命令不能假设 DSH、Codex、OpenCode 原生兼容；客户端能力需要单独验证。
- 全功能验收不代表每次小修改都重跑所有检查。保留用户要求的完整交付门槛，并区分阶段验证。

## 推荐下一版范围

基础模板少量增加：生命周期取消、依赖同步、回归复现、对外内容审查与有效验证复用；纠正模拟测试措辞。
项目模板补齐：可执行命令、工具链、运行态、测试入口、受管数据和发布权限。
可选片段承载：UI 完整性、数据库迁移与回滚、性能预算、Rust 缓存策略等具体细节；后两项属于项目需求推导，不冒充此次公开资料的直接结论。
生成工具负责：拼接顺序、冲突检测、版本记录、定制保护。无需继续把所有细节堆进基础模板。
