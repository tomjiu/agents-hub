# AGENTS.md 模板与拼接素材

当前为审阅草稿，尚未部署到任何项目。基础候选拼接命令已实现并通过隔离测试；客户端读取项目规范的实际验收及自动语义冲突检查尚未完成。

本仓接手规范与通用模板分开：[根AGENTS.md](../AGENTS.md)含本仓登记、发现、DSH搜索/记忆和预选技能操作；不要把它复制到所有消费项目，以下共用模板仍按项目审查。

## 三个使用素材

| 素材 | 用途 |
|---|---|
| [共用基础规范](base/AGENTS.md) | 跨项目的开发、证据、测试、安全、卫生与交付纪律，版本 0.3.0-draft |
| [项目专属填写模板](templates/project.md) | 本项目的实际入口、命令、架构、验收、协作和资源边界 |
| [UI 验收片段](fragments/ui-acceptance.md) | UI 项目按需加入的键盘、焦点、多状态和交互验收要求 |

## 当前可用的手工拼接流程

1. 从项目现有规则、实现与已批准的约定填写项目专属模板；有价值的特有规则保留，不用共用模板整份替换旧规范。
2. 选择适用片段。当前只有 UI 验收片段，不假定其他语言或场景片段已经实现。
3. 按“共用基础正文 → 已选片段正文 → 填写后的项目正文”组合候选文本。该顺序是组织方式，不赋予后段隐式覆盖前段的权力。
4. 检查重复和冲突、实际路径与命令、项目定制是否保留；待填写项不得被当成命令执行。未解决的关键冲突不发布为正式规范。
5. 展示候选文本与原项目规则的差异，经确认后保存到项目根 AGENTS.md。记录模板版本和已选片段；最终正文必须完整，不依赖本仓的动态 include。
6. 在实际客户端验证它是否读取了预期规则，并完成代表性任务核对。仅生成文件不代表客户端已加载，也不能保证模型始终遵循。

项目事实应明确说明命令适用的工作目录、工具版本、前置条件、运行风险与验证状态。无法实跑的命令标 NOT RUN，不伪装成通过。

## 候选生成失败保护

compose检查来源哈希、空内容/占位项和重复片段；独占锁，先发布来源记录再发布正文，不覆盖现有内容。源变化或写入失败不正常交付；强杀可能留锁/sidecar，需人工核查。语义冲突仍需人工审阅，详见 [失败保护说明](../asset-manager/FAILURE-PROTECTION.md)。
