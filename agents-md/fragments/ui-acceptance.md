## UI 功能验收片段

<!-- agents-hub fragment: ui-acceptance / version: 0.1.0-draft -->

适用范围：涉及用户界面或交互的功能。与基础规范的真实点击、前后端接线要求配合使用；不适用的场景应明确说明理由。

- 从真实产品入口启动，记录正在测试的构建版本与环境。优先复用已运行的实例；需要重启时只处理属于本任务且已确认身份的实例。
- 对需求内的交互执行真实点击、输入、导航、确认和取消；观察界面、请求/IPC、后端处理和保存结果。刷新或重开后检查需要持久化的状态。
- 覆盖加载中、空数据、失败、超时、成功状态；错误信息可理解且能恢复，不能以永久 loading 或吞掉错误冒充成功。
- 检查键盘导航、焦点顺序、可访问名称及适用的快捷键；打开/关闭弹窗后焦点应可预测，不只验证鼠标路径。
- 检查项目支持范围内的窗口尺寸、缩放、长文本和本地化；沿用现有设计系统与本地化机制，不新增独立硬编码体系。
- 对有副作用的提交验证重复点击、并发请求和取消行为；适用时核查禁用状态、幂等处理与失败后重试，防止重复写入或误操作。
- 检查权限不足、会话失效及前后端返回不一致的表现。用隔离数据测试，不为验收操作未经授权的生产账户或用户数据。
- 按功能清单保存操作、预期、实际结果及必要截图/日志。截图用于呈现结果，不替代交互断言；合成事件或测试替身不能冒充真实产品验收。
- 工具无法操作真实界面时，可完成静态或组件检查，但必须将真实交互验收标为未验证，并说明需要的环境与剩余步骤。
