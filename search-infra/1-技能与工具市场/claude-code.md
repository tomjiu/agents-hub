# Claude Code · 技能与工具市场

> **一句话**：Claude Code 是 SKILL.md 格式的发明者，也是唯一把"技能市场"做成带完整安全工程的产品的——别的家都是抄它的格式，它自己连"安装包怎么防坏人"都想好了。

## 背景

Anthropic 官方 CLI。本次分析拆了三样东西：npm 安装包、206MB 的原生二进制（strings 提取了 27 万行）、Windows 桌面安装器。

## 技能是什么样

一个技能 = 一个文件夹 + 一个 `SKILL.md`（开头几行写名字和用途，正文写操作指南）。技能从五个地方来：

1. 项目里 `.claude/skills/`
2. 用户全局 `~/.claude/skills/`
3. 插件自带的 skills/
4. MCP 服务器提供的
5. claude.ai 账号云同步的

两个细节值得注意：

- **超过 128KB 的 SKILL.md 会被直接跳过**——他们用硬限制防止一个巨型技能文件吃掉上下文。
- **每次只给目录**：AI 每轮看到的只是"名字: 一句话简介"的列表。要用某个技能时，才用 Skill 工具把全文加载进来。加载过且内容没变的重复调用，会被压缩成一行（省 token）。

## 市场是怎么做的（全行业最完整）

在 Claude Code 里，"插件"是比技能更大的打包单位：一个插件 = 技能 + 子代理 + 钩子 + MCP 服务器 + 主题等一整套东西，用 `plugin.json` 做清单。安装市场支持两种来源：git 仓库或 URL。

从二进制里挖出来的安全设计，每一条都是真实踩坑后的产物：

| 设计 | 防的是什么 |
|------|-----------|
| 安装到"版本锁定"的缓存目录 | 升级后旧版本还在，出问题可回滚 |
| 强制不用符号链接、防路径穿越 | 恶意插件用 `../../` 逃出安装目录写任意文件 |
| `installed_plugins.json` 记录状态（还有 v1→v2 迁移逻辑） | 用户卸载/升级后状态错乱 |
| 企业黑名单在**下载前**拦截域名 | 公司禁止的插件根本到不了磁盘 |
| SSH known_hosts 变化就拦截，并给出 `ssh-keygen -R` 修复指引 | 下载源被劫持（中间人攻击） |
| `claude plugin eval` 命令 + `/skill-doctor` | 技能装上后好不好用，有评测/体检工具 |

## 工具太多怎么办：三级渐进披露

Claude Code 自己就有几十个工具，再加上用户接的 MCP 服务器，工具描述能把上下文挤爆。它的解法分三级：

1. **平时**：工具描述的总字符量超过上下文窗口的某个百分比 → 自动把不常用的工具转成"暗牌"，提示词里只留名字。
2. **找工具**：模型用 `ToolSearch` 工具按需取回完整定义。支持两种写法：`select:Read,Edit,Grep`（按名字精确取）或关键词搜索。
3. **打分逻辑是手写的**（不是 BM25）：名字命中 +10、子串 +5、描述命中 +2…… 每个工具还配了一句"检索提示"（比如 WebSearch 的提示是"search the web for current information"），搜索时这句提示也参与匹配。

一个有意思的产品细节：Chrome 工具的提示词里写着"把要用的工具合并进一次 select:——每搜一次就浪费一整个来回"。连"教 AI 省调用次数"都想到了。

## 值得我们抄的清单

| 抄什么 | 为什么 |
|--------|--------|
| SKILL.md + "目录先行、按需加载" | 已成行业标准，兼容成本为零 |
| 每个工具配一句 searchHint | 成本极低，检索准确率明显提升 |
| 市场安全五件套（版本锁定/防穿越/前置黑名单/MITM 检测/状态文件） | 做公开分发时绕不开 |
| 128KB 硬上限 + 重复加载去重 | 简单粗暴有效的上下文保护 |

## 别学的坑

- 打分逻辑手写意味着每个工具都要人工调权重——工具少时没问题，规模化后不如 BM25（Codex 的做法）。
